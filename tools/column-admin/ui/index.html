    一度保存したURL名は固定です。

    見出しは「## 見出し」、箇条書きは「- 項目」。空行で段落を分けます。HTMLは文章として表示されます。

    1行に「資料名 | https://…」。登録したURLを本文にも書くと、公開ページで参照元へのリンクとして表示します。

    確定・取り下げ後も、実サイトに反映するには配信が必要です。取り下げても下書きは残ります。

    記事を選ぶか、新しく書き始めます。
