# ウェブ制作・EC教材の参考資料と再構成案

確認日：2026-11-09。調査後、ユーザーがウェブ三テーマの実装を承認。ECは追加教材を作らずページごと削除する指示に変更。以下のEC候補は過去の調査記録。

## 今回の指示と現状

ユーザー指定の次のウェブ制作構成は、1.文字サイズと余白、2.配色、3.レスポンシブの配置。現在の余白・段落・情報整理は重複感があるため第一項へ統合する方向。配色は現状の文字色の比較だけでは意図が伝わらないため、サイト全体の色と印象を扱う参考資料を探す。

ECも資料を調べ直す。過去の確定方針は、購入前の見せ方より購入後の管理・運用を重視すること。以下のEC三分類は今回の提案であり、ウェブ制作の三分類と同じ程度にユーザーが確定したものとは扱わない。

## ウェブ制作：テーマ別の候補

### 1. 文字サイズと余白

- デジタル庁：タイポグラフィ https://design.digital.go.jp/dads/foundations/typography/
  - 書体の大きさ・太さ・行の高さ・テキストの役割の整理。日本語の設計根拠として適する。
- Adobe：余白のクイズ https://www.adobe.com/jp/creativecloud/roc/blog/design/quiz-challenge/margin.html
  - 二段組み、全体の余白、印刷向けの余白のA/B図と解説。ウェブでは印刷の断裁部分をそのまま転用しない。
- Google web.dev：タイポグラフィ https://web.dev/learn/design/typography?hl=ja
  - 文字サイズ・行長・行間・読者の設定への対応。実装の裏付け用。

教材案：同じお知らせで「見出しと本文のサイズ差」「関連する要素の間隔」を見比べる。余白・段落・情報整理を別々の問題として重複させない。読みやすさと優先順位が主題。

### 2. 配色

- 第一候補：Adobe「見やすさと世界観を両立する配色」 https://www.adobe.com/jp/creativecloud/roc/blog/design/quiz-challenge/color-palette.html
  - 内容の見つけやすさ、テーマと背景の相性、文章の読みやすさを作例で扱う。現状の文字色だけの比較より希望に近い。
- 補助候補：Canva「配色・色の組み合わせ100選」 https://www.canva.com/ja_jp/learn/100-color-combinations/
  - 色コード付きの多数の組み合わせを比較できる。パレットと全体の印象を考える資料。
- 確認用：デジタル庁カラー https://design.digital.go.jp/dads/foundations/color/
  - 色の役割と一貫性の裏付け。前回調査済み。

教材案：同じ写真・内容・配置で背景／文字／ボタンの配色セットを切り替え、全体の印象を見比べる。色の面積配分と文字の読める明暗差も示す。色数を減らすだけ、固定比率なら必ず正解、青なら必ず信頼、という単純な説明にしない。個人の好みを絶対的な正誤として採点しない。

### 3. レスポンシブの配置

- 第一候補：Google web.dev「マクロのレイアウト」 https://web.dev/learn/design/macro-layouts?hl=ja
  - 広い画面の複数列と狭い画面の一列、配置の前に読む順序を整える説明。図と実例あり。
- 全体の学習目次：Google web.dev「レスポンシブデザインを学ぶ」 https://web.dev/learn/design?hl=ja
  - ページ全体・部品・文字・画像の章へ分かれた学習資料。

教材案：PC／タブレット／スマホのプレビューを切り替え、複数列から一列、画像と説明の配置、ボタンの幅、余白が変わることを見る。単純縮小と適切な組み直しを比較する。重要情報をスマホだけ隠したり、表示順と読み上げ順を食い違わせない。

## EC：購入後の管理に関する候補

### 1. 受注から発送まで

- ネクストエンジン：機能一覧 https://next-engine.net/functions/
  - 受注・決済・在庫・送り状・倉庫連携の関係、受注管理の流れを見せる構成。
- Shopify：注文状況 https://help.shopify.com/ja/manual/fulfillment/managing-orders/order-status
  - 注文、決済、出荷、返品を分けた状態の説明。

教材案：「入金待ち」「出荷待ち」「一部発送」の注文から、今処理できるものと止める理由を判断する。店ごとの前払い・後払い等の条件を先に明示。

### 2. 在庫と複数の販売先の連携

- Shopify：EC在庫管理の完全ガイド https://www.shopify.com/jp/blog/ec-inventory-management-guide
  - 入荷から出荷・返品・棚卸までの全体像、複数販売先やシステム連携の課題。
- Shopify：在庫状態 https://help.shopify.com/ja/manual/inventory-and-locations/fundamentals/inventory-states
  - 手持ち、販売可能、引き当て済み、利用不可、入荷予定の区別。

教材案：最後の一個がネットで売れた場合に、店頭や別モールの販売可能数をどう扱うかを見る。算数だけの問題から、同期と売り越し防止の判断へ発展。

### 3. 返品・返金・交換

- Shopify：返品と交換 https://help.shopify.com/ja/manual/fulfillment/managing-orders/returns
  - 返品依頼、返送、検品、返金、交換の関係。

教材案：サイズ交換・破損・一部返品で、返金額と在庫へ戻せる数を別々に判断する。規約や法的義務を一律に断定せず、架空店舗の条件を示した運用例に限定。

## 作り方の提案と未確定事項

- ウェブ：視覚的な変化が主役。文字・余白は比較、配色は切り替え＋理由、レスポンシブは画面幅の切り替え。
- EC：実務の場面と管理画面が主役。注文を選ぶ→次の操作を考える→理由を読む。公式製品の画面や教材を転載せず、独自の見本にする。
- 各記事は全文転載ではなく、考え方と見せ方の参考にする。製品固有の仕様をすべてのECに共通するルールとしない。
- ウェブ三テーマは実装対象として確定。EC三分類は不採用とし、詳細ページを削除する。
