# サイト全体の表示密度

変更履歴: 2026-11-11 ユーザーの全ページの余白統一・フッター縦間隔削減の指定を実装。

## 方針
セクションはPC56px、スマホ40pxを基準とし、見出しから本文は20〜24px、関連する内容は12〜16pxにまとめる。本文の行間・文字サイズを一括縮小せず、スマホの読みやすさを維持する。ヒーロー演出、画像、カードのスクロール、問い合わせと照会の機能は変更しない。

会社概要・企業理念・料金・サービス一覧と詳細・調査案内・安全チェック・記事に共通ルールを適用。メインの開始位置を固定ヘッダーと重ならない範囲に短縮。調査案内の末尾90pxと共通末尾の二重余白を解消。

フッターのリンク行はPC最小28px、スマホ32pxへ短縮。長い項目は折り返しに応じて高さが伸びる。リンク間の最低領域を確保し、ロゴ・見出し・本文・運営者の順序は維持する。

## 確認範囲
公開前にビルド・既存テストと、PC・スマホ幅の代表ページをブラウザで確認する。実機端末・Safariは対象外。
