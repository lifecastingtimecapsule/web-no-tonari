# Search Console設定と記事のSEO手順の適用

変更履歴: 2026-11-11 所有権確認・サイトマップ送信・Google URL検査を実施。ユーザー添付のSEO記事を事実と運用上の提案に分けて採用。

## Search Console
既存の利用中Googleアカウントへsite-veil.comのドメインプロパティを追加。Cloudflare DNSへGoogle指定の確認用TXTを1件追加し、所有権確認成功。既存のメール・配信レコードは変更しない。確認維持のためTXTを残す。DNSアカウント連携の権限は新規に付与しない。

https://site-veil.com/sitemap.xml を送信。初期の「取得できませんでした」は、その後「正常に処理されました」へ変化し、13ページの検出を確認。ホームは「検出 - インデックス未登録」。Google公開URLテストで「URLはGoogleに登録できます」を確認し、インデックス登録をリクエスト。優先クロールキューへの追加成功を確認。登録申請と実際の検索登録は別であり、検索掲載完了とは報告しない。

検索パフォーマンスとインデックス集計はデータ処理中。表示・クリック・順位・検索回数を0や推定値で埋めない。

## 添付記事から採用したこと
実データで優先順位を選ぶ、既存ページを先に改善する、実際の提供範囲・価格・成果物で情報を補う、タイトル・内部リンク・画像・構造化データ・サイトマップを検証する、公開後に観測する。モデル名・価格・速度・特定製品の宣伝や実績は未検証として採用しない。別サービス契約やモデルのインストールは行わない。必須H1数・リンク本数・文字数・60日の一律待機をGoogleの規則とは扱わない。

## 検索意図と既存ページの対応（仮説）
| 読者が探す内容の候補 | 改善する既存ページ | 独自の判断材料 |
|---|---|---|
| 大府市のホームページ制作・サイトのリニューアル | /services/websites/ | 5ページまでの税込料金、原稿・画像・公開範囲 |
| 小さな会社のSEO診断・サイト改善 | /services/seo/ | 主要5ページ、診断と修正の区別 |
| Excelから顧客管理・受注管理へ移行 | /services/ai-apps/ | 業務別の制作費と月額、利用人数・含む機能 |
| サイトの安全確認・小規模システムの検査 | /services/security/ | 基本・詳細・侵入テストの違いと範囲、郵送報告書 |
| 制作・保守・システム検査の費用 | /pricing/ | 共通料金データ、追加費用と対象外 |

上記は実測検索数に基づくランキングではない。新しい重複ページは量産せず、検索データが使えるようになったら検索語×URL×表示×クリック×期間を確認し、優先するページを決める。初期は記事の「5〜15位」「過去28日」の条件に該当する実データがないため、その形式の成果を作らない。

## 今回の反映
前回のタイトル・説明・パンくず・クロール設定を維持。今回、セキュリティページの情報不足を実際の新プラン、料金目安、対象上限、調査方法と結果を記す郵送報告書で補い、料金ページ・案内ページと共通化。問い合わせで金額を自動入力しない指定と、説明末尾の問い合わせを維持。
