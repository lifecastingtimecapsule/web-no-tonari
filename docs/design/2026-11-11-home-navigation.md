# ホームとロゴ表示

変更履歴: 2026-11-11 送信ボタン中央配置に続き、ロゴの表示遅れとホーム導線を修正。

- ロゴをヒーロー全体の通過後から、スクロール開始（1px超）で表示へ変更。ページ先頭では隠し、先頭へ戻ると再び隠す。フェードは80ms。
- 背景を白へ切り替えるヒーロー通過の判定は維持し、ロゴ表示とは分離。受動スクロールイベントで既存処理を使い、スクロールを妨げない。
- メインナビ先頭にホームを追加。ロゴはヒーロー直下ではなく、ホームの#topへ戻す。ヘッダー・フッター共通。以前の「ロゴはヒーロー下へ」の方針は今回の指定で更新。
- 送信ボタンは中央。スマホ全幅の押しやすさは維持。

確認: 390pxで先頭はロゴ非表示、127pxスクロールしてヒーローが残る段階で表示、ロゴクリックで#top・scrollY=0へ戻ることを確認。スマホのホームリンクでメニューが閉じ、他ページのロゴからも先頭へ戻る。901px・1024px・1280pxでナビのはみ出しなし。送信ボタンは390px/1280pxでフォーム中心との差0px。Astro62ファイルのエラー・警告0、18ページ生成成功。
