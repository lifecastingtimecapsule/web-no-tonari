# セキュリティサービスの入口と名称の整理

変更履歴：2026-11-10、既存Webサイトを活用し、別々のARTEX/Strix検査と会社・案件管理へつなぐ要望を記録。ユーザーは受付メール未作成のため、先にサービス名を固めたいと回答した。名称確定前にメールアドレスや新ブランドを作成・公開しない。

## 決まっていること
- 既存のウェブのとなり、公開簡易チェック、漏洩調査、公開情報調査、ARTEX、Strixを活用する。
- Strixは提供コードなどの弱点を探す検査、ARTEXは攻撃経路・影響の検証の役割として別々に管理する。
- 現在の提供コピー検査と記録管理だけで、顧客本番への攻撃検証を実装済みとは表示しない。
- 顧客の入口は3分類：サイトの状態、メールの漏洩、システムの詳しい検査。
- 簡易チェックは無料の既存ページへ。詳しい調査は対象と同意範囲を確認してから見積・実施。価格や提供開始日を新しく確約しない。
- 会社・案件管理画面は運用者専用。公開サイトからlocalhostへ顧客を案内しない。

## 確認中
サービス全体の名称を、既存ブランドを使う「ウェブのとなり セキュリティ」、専用名「となりのセキュリティ」、新しい別ブランドのどれにするか確認中。商標・ドメイン・メールアドレスの取得可能性を確認済みとは扱わない。

## 名称確定後の実装案
既存の白・墨・赤、既存書体と左揃えを継承。公開サイトに「何を確かめたいか」の入口を配置し、詳しい検査の中で弱点を探す検査と影響を確かめる検証を説明する。教材・簡易チェック・料金・相談をつなぐ。既存のサービス/料金の独立ページと、受付未接続の表示は維持。

```
何を確かめたいですか
  サイトの状態 → 公開簡易チェック / 管理状況の相談
  メールの漏洩 → 調査範囲・郵送報告の案内
  システムの弱点 → 脆弱性検査 / 必要な攻撃経路の検証
相談内容の準備 → 対象・範囲の合意 → 検査 → 結果の報告
```

受付メールの作成はサービス名と送信先が確定してから。送信機能のないフォームで送信完了とは表示しない。公開サイトの変更・デプロイは今回はまだ行っていない。
