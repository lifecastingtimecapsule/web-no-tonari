# 参考サイト比較と文字サイズの方針

## 確定した希望

2026-11-13、令和ホームページとSITEVEILの比較中に、ユーザーは「文字のサイズはこんな感じでいい」「今後のサイト・コーディングのスキルとして覚えて」と指定した。可読性を保つ現在のサイズ感を尊重する。具体的なpx値や書体の指定とは解釈しない。

見た目の改善は、文字を小さくすることや見出しを一律に大型化することから始めない。配置・整列・行幅・余白・写真や画面の見せ方・色の役割・情報の順序を優先する。今回の依頼は比較と方針記録であり、公開サイトのデザイン変更は実施しない。

## 実画面で確認した比較

- 参考：https://reiwa-homepage.jp/ 。価格・制作内容・完成イメージを最初に提示。青系の配色、実際に見られるテンプレートの画像、反復する相談導線が一貫している。一方、相談ブロックの反復は多く、全てをコピーする必要はない。
- SITEVEIL：https://site-veil.com/ 。ロゴと流体アニメーションが最初の主役。次に安全チェック、4サービス、料金と目的が切り替わる。サービスカード画像は説明用画面が中心で、完成物の質感は伝わりにくい。演出と実務情報のつながりを整える余地がある。
- 参考サイトの「統一と分かりやすさ」を学び、青への色替えや文章・条件の模倣は行わない。SITEVEILの暖色と白地、本人の文字サイズの好みを尊重する。
