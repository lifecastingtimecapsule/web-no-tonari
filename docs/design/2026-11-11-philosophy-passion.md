# 企業理念の改稿

変更履歴: 2026-11-11 ユーザーの「カタルシス的に、パッションを持って」という依頼を反映。

理念を「やりたい仕事に、夢中になれる毎日を。」へ。届けたい価値があるのに日々の手間や不安に追われる状況から、「もっと、こうしたい」を取り戻す展開にする。最後は挑戦に技術で応える意思で結ぶ。

既存の3つの姿勢（事業理解・説明の誠実さ・継続利用）を残して具体化。創業者の体験談、未確認の実績、無条件の保守や安全の保証は追加しない。料金や契約範囲、画面構成は変更せず、理念本文と検索向け説明を更新する。
