# 登録不要のフィッシング体験

## 確定した方向

ユーザーがGoogle / Jigsawのクイズ形式を選択し、名前・メール入力を省き、フィッシングの判定・怪しい箇所の指摘・危険なリンクを開いたときの演出を依頼した。前回の情報量過多を受け、SMS一通だけで完結させる。2026-11-09の参考候補一覧で保留した実装を、この選択に基づき再開。

## 体験

- 初期表示：iPhoneを参考にした受信SMSと、短い問い。フォームや開始前の登録はない。
- 怪しい箇所：番号・期限・URLの3箇所。押すと隣（スマホでは下）の同じ領域に短い説明。番号や期限だけでは詐欺と断定しない。
- 全体の判定：「フィッシングだと思う」で、この例の狙いと対策を表示。
- 疑似リンク：「リンクを開く（体験）」で赤い警告と一度だけ340msの表示演出。「情報を盗まれた」とは断言せず、偽の支払い画面への誘導を説明する。
- URL文字を押す操作は指摘、別ボタンは開く体験とラベルで区別。実際の外部遷移・入力欄・保存・送信・音・点滅はない。
- 結果後も他の箇所を調べられ、「もう一度見る」で初期化。
- 出典と困ったときの確認先は折り畳み。PHPは `/services/security/php/` の記事へ分離。

日本郵便の名称は説明対象として使い、公式教材・提携の表示はしない。番号は伏せ字、URLは予約ドメイン.test。番号を正規のSMS送信元として再現したという主張はしない。Googleの画像・文章・問題は転載しない。

## デザイン

frontend-design・Impeccableの指針を適用。白 #FFFFFF、本文 #151517（既存ink）、補助灰色、ブランド赤、受信吹き出し #E9E9EB、疑似警告 #FFF0F2。共通のZen Kaku Gothic / Noto Sans JPを維持し、端末内だけiPhoneに近いシステム書体。端末340px＋左揃えの判断欄、640px以下では縦積み。演出は疑似リンクの回答時のみ。

## 検証

- Astro check 35ファイル：エラー・警告0。静的10ページの生成成功。
- 1440/768/375/320pxで3箇所＋2ボタンの全5操作とリセットを確認。横はみ出しなし。
- キーボードEnter、結果見出しへのフォーカス、JavaScriptなしの解説開閉を確認。
- reduced-motion時のアニメーション0、通常時1、再挑戦によるキャンセル0を確認。
- 偽ドメインへのリクエスト0、ブラウザ実行エラー0、体験内入力欄0。
- PHPへの内部リンクと320pxの表を確認。掲載8系統。
- Impeccable detector指摘0。Web Interface Guidelinesで標準button、フォーカス、表示切替、折り返し、見出し階層を確認。
