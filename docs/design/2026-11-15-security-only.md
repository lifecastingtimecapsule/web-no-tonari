# SITEVEIL セキュリティ専門への転換

変更履歴：2026-11-15、利用者の「制作等をやめて全てセキュリティ会社へ書き換える」指示を反映。11月14日までの複数事業の案内より本方針を優先する。

SITEVEILは株式会社ライフキャスティングジャパンのセキュリティ専門サービスとして案内する。法人の商号・法的事業内容の登記変更は行わない。サイト・メールの無料チェック、既存価格の基本確認・詳細検査・侵入テスト・保守・PHP更新を中心に再構成。新しい監視・緊急対応・資格・実績・安全保証は追加しない。料金・調査の合意範囲・郵送・30日保管の条件を維持。

ホーム、サービス一覧、料金、会社概要、理念、メタ情報・共有画像、共通ナビ・サイトマップを更新。制作・SEO・業務開発の旧サービスURLは現サービスへ転送。音声・電話受付は非公開を維持。冒頭のモヤモヤと日本語中心の簡素な見た目、既存問い合わせ・無料チェックの機能を維持する。

検証：既存テスト、旧サービスの公開生成物への残存確認、メタ情報、サイトマップ、スマホとPC、旧URLの転送と音声404、公開処理の成功を確認する。顧客照会・メール実送信・攻撃実行は行わない。

検証結果：76テスト成功、型検査81ファイル0エラー・0警告、16ページ本番build成功、下書き混入検査成功。主要10経路を320/390/1280pxで実ブラウザ確認し、横はみ出しと旧3事業の案内なし。FAQとメニュー開閉を確認。旧3事業URLの転送と音声非公開の回帰検査も成功。実送信・顧客照会・攻撃実行なし。

## 2026-11-15 明るいセキュリティサービス再設計

変更履歴：MotionSitesのInk Revealを現行ヒーローの参考、SANKOU!掲載のSimpleFormを本文の余白・日本語見出し・罫線による情報整理の参考として選定。利用者の承認により、ヒーロー直後の安全チェックは文言、入力欄、配色、文字の強弱、右側の確認イメージを含めて変更しない固定範囲とした。

ヒーローと安全チェックより下へ「確認できるリスクを、早期に見つける。」を配置。単発リスクチェックと定期リスクウォッチ、更新情報の通知と更新作業、複製環境だけで行う侵入テスト、確認済み・未確認を分ける報告書の順で説明する。本文は白と墨色を基本に、青を単発、紫を定期、橙を複製環境の意味へ限定し、角丸カードの連続と本文の自動アニメーションを使わない。

共通データ `security-service-policy.ts` を追加し、ホーム、サービス仕様、利用規約の境界表現を共有する。サービス仕様は確認項目、頻度案、通知、別作業、中止条件、成果物を表示。利用規約案は完全保証をしないこと、誤検知・見逃し、顧客の管理権限と協力、第三者サービス、調査データ、責任制限と法令上の例外を表示する。個別契約、本規約、サービスサイトの順に優先する。

変更しない固定範囲：`VeilHero.astro`、`veil-motion.ts`、`ink-static.svg`、`SafetyCheck.astro`。前後の接続は次のセクション側だけで調整する。

検証結果：90テスト成功。Astro型検査87ファイル0エラー・0警告、18ページ本番build成功、内部用下書きの公開混入なし。ホーム、セキュリティ詳細、料金、サービス仕様、利用規約を1280×900、390×844、320×720で確認し、横はみ出しなし、スマホ一列、メニュー表示、キーボードフォーカス、本文の新規自動アニメーションなしを確認。ヒーローはPC・スマホとも変更前後で見出し、ロゴ幅、矢印、キャンバス構成が一致。安全チェックは文言、2列寸法、入力欄幅、右側表示高が一致した。

未確定：定期リスクウォッチの公開頻度と通知期限は運用検証後に契約前確定する。現在の頻度は基準案であり保証値ではない。利用規約の責任制限、消費者契約への適用、合意管轄は、実際の顧客属性と運用に合わせた専門家確認前の案であり、その確認前に確定条件として使用しない。
