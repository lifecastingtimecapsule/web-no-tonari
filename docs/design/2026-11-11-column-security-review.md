# コラム・ローカル管理の検証記録

変更履歴: 2026-11-11 コラム投稿機能の追加に伴い、変更範囲の認証・入力・非公開境界を重点点検。

## 対象と結論
対象は `tools/column-admin/`、`src/data/columns.*`、コラム2ページ、ナビ・フッター・サイトマップ・配信設定。既存の漏えい照会API全体やOSを含む全面監査ではない。公開サイトへの攻撃・負荷試験や第三者環境への通信試験はしていない。

新しい管理機能は127.0.0.1:8792のみ。独立したソースレビューでは、外部からの認証迂回・CSRF・スクリプト実行・任意ファイル読み出し・下書きの公開につながる具体的な不具合は見つからなかった。これは完全な安全性の保証ではない。

## 検査と証拠
- 既存テスト66件成功。
- ローカル管理の境界テスト10件成功: 入力の長さ・URL名、HTML非解釈、公開項目の限定、未認証、Host/Origin/CSRF、更新競合、公開・取り下げ、ログアウト、初回設定の保護、ログイン制限、過大リクエスト、30分の期限、外部変更による上書き防止、10文字の設定・9文字の拒否。
- テストには架空の記事、架空のパスワード、一時ディレクトリを使用。本番の下書き・本人のパスワードを使わない。
- ブラウザ用の使い捨てコピーで、初回設定、下書き作成・保存、プレビュー、公開用反映、取り下げ、ログアウトを実操作。
- 架空の本文 `<script>window.TEST_EXECUTED=true</script>` はテキストとして表示。プレビュー配下のscript/img/iframeは0件。外部への攻撃通信なし。
- ログアウト後、本文欄が空、プレビュー要素0、編集画面非表示をDOMで確認。
- 下書き保存後も検査コピーの公開JSONは空のまま。検査コピーは終了後削除。本人用の管理データとは独立。
- lsofで待ち受け先が127.0.0.1:8792であることを確認。
- 320/390/1280pxでコラム一覧・記事の横はみ出しなし。管理UIも同3サイズで確認。デスクトップ画像は再撮影し独立した目視レビューで収まりを確認。
- スマホのメニュー開閉、記事の表示、一覧へ戻る操作を確認。
- Astroビルドのエラー・警告0、22ページ生成。内部リンク・JSON-LDを22 HTMLで検証、サイトマップ17 URL。
- 公開生成物の管理ファイル・認証・検査用下書き混入チェックに成功。以後も配信前に10件の境界テストと生成物の検査を自動実行する。
- `npm audit --json` および `--omit=dev` の照合結果は、2026-11-11の実行時点で既知の脆弱性0件。新規外部パッケージは追加していない。

## 点検中に修正したこと
- 保存中に書いた文字が消える可能性: 保存中はボタンに加えて入力欄を無効化。処理後に解除。
- 期限切れでも画面に記事が残る状態: 有効期限を画面へ渡し、2分前に保存を案内。30分後および非表示からの復帰時にログイン状態を検査し、本文・プレビューを消去。
- 初回パスワードの長さ: 本人の指定で10文字以上へ変更。ハッシュ化・試行回数制限は維持。
- 生成物検査のURL型とパス型の不一致: ファイルパスに変換して修正し再実行成功。

## 運用上の境界・未実施
- パスワードは本人が設定。既定値なし。本人用初回設定は別途画面で行う。チャットへ送らない。
- 管理画面はHTTPのループバック専用。CookieはHttpOnly・SameSite=Strict。HTTPのためSecure属性は付けず、外部プロキシ・トンネルには使用しない。
- 同じOSアカウントへの侵入、Macのマルウェア、ディスク暗号化・バックアップ、別端末を使った侵入試験は対象外。
- ログインは30分固定。期限を過ぎると未保存の内容は消える。こまめに保存する。
- 公開用確定と実サイトの配信を意図的に分離。チャットで公開を依頼する運用。公開・取り下げとも配信完了前は実サイトは変わらない。
- ローカル下書きは暗号化保存ではない。OSの本人権限とファイル権限で守る。パスワードだけは不可逆ハッシュ。
- 正式な第三者監査、完全隔離した攻撃試験、長時間稼働監視は未実施。上記の機能確認・重点ソース点検の結果として扱う。
